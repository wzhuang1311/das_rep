# 第一步速查卡（VSCode 操作，从上往下照着做）

> 目标：建好虚拟环境 + 装上 CUDA 版 PyTorch，直到 `env_check.py` 全部 `[OK]`。
> 详细原理和报错对照表见 `01_环境配置_CUDA.md`。本文件只管"手怎么动"。

---

## 第 1 步：用 VSCode 打开正确的文件夹

1. 打开 VSCode
2. 左上角菜单：**文件 (File) → 打开文件夹 (Open Folder…)**
3. 在弹出的路径框里，**粘贴**这一行，然后回车：

   ```
   D:\汕头大学\科研\深度学习\text.demo\das_rep
   ```

4. 如果弹出"是否信任此文件夹中文件的作者？" → 点 **是，我信任此作者**

**成功标志**：左侧资源管理器里能看到 `checkpoints`、`docs`、`results` 三个文件夹和 `env_check.py`。

> ❌ 不要用"打开文件"打开 `.py` 或 `.md`——那样 VSCode 的工作目录不对，
> 后面 `pip install` 会装错地方。
> ✅ 一定要用"**打开文件夹**"，并且开的是 `das_rep`（不是 `das_data`，也不是 `text.demo`）。

---

## 第 2 步：打开终端

按快捷键 **`` Ctrl + ` ``**（Ctrl 加键盘左上角 Esc 下面那个反引号键）。

或者用菜单：**终端 (Terminal) → 新建终端 (New Terminal)**。

**成功标志**：VSCode 下方弹出一个终端面板，提示符大概长这样：

```
PS D:\汕头大学\科研\深度学习\text.demo\das_rep>
```

> 如果显示的路径不是 `das_rep`，敲这一行切过去（**路径有中文和空格，双引号不能省**）：
> ```powershell
> cd "D:\汕头大学\科研\深度学习\text.demo\das_rep"
> ```

---

## 第 3 步：创建虚拟环境（约 15 秒）

在终端里敲：

```powershell
py -3.13 -m venv .venv
```

**成功标志**：没有任何输出（静默成功），左侧资源管理器里多出一个 `.venv` 文件夹。

> 如果提示 `py 不是内部或外部命令`，改用完整路径：
> ```powershell
> & "C:\Users\34667\AppData\Local\Programs\Python\Python313\python.exe" -m venv .venv
> ```

---

## 第 4 步：激活虚拟环境

```powershell
.\.venv\Scripts\Activate.ps1
```

**成功标志**：提示符前面多出 **`(.venv)`**，变成这样：

```
(.venv) PS D:\汕头大学\科研\深度学习\text.demo\das_rep>
```

> ⚠️ **看不到 `(.venv)` 就是没激活成功，后面全部会装错位置，停下来问我。**
>
> 如果报错"无法加载文件 Activate.ps1，因为在此系统上禁止运行脚本"，先敲这行再重试第 4 步：
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```

---

## 第 5 步：安装 CUDA 版 PyTorch（最久，约 3 GB，泡杯茶）

```powershell
python -m pip install torch==2.12.0+cu130 torchvision --index-url https://download.pytorch.org/whl/cu130
```

**成功标志**：最后一行是 `Successfully installed torch-2.12.0+cu130 ...`

> 中途断了不要紧，重敲同一条命令，pip 会接着下。

---

## 第 6 步：安装其余依赖

```powershell
python -m pip install numpy scipy scikit-learn matplotlib pandas
```

---

## 第 7 步：运行自检脚本

```powershell
python env_check.py
```

**成功标志**：最后显示

```
 全部通过！环境已就绪，可以进入阶段 1（数据可视化）。
```

并且 `cuda.is_available()` 那一行是 `True`、GPU 名称显示 `NVIDIA GeForce RTX 4050 Laptop GPU`。

---

## 第 8 步：让 VSCode 记住这个环境（很重要，否则以后点"运行"还是用错的 Python）

1. 按 **`Ctrl + Shift + P`** 打开命令面板
2. 输入 `Python: Select Interpreter`，回车
3. 在列表里选带 **`.venv`** 的那个，路径应该是：
   `D:\汕头大学\科研\深度学习\text.demo\das_rep\.venv\Scripts\python.exe`
4. 选完后看 VSCode **右下角状态栏**，会显示 `.venv (Python 3.13.7)`

**成功标志**：右下角显示 `.venv`。

## 出问题时的通用求助方法

把**这三样东西**一起发我，我能立刻定位：

1. 你敲的那条命令（原文）
2. 终端的**完整报错**（从报错那行往上多复制几行，别只复制最后一行）
3. `python env_check.py` 的输出（如果它能跑起来）

另外，在任何一步，都可以随时敲这两条命令来"体检"：

```powershell
python -c "import sys; print(sys.executable)"     # 当前用的是哪个 Python
python -m pip show torch                          # torch 装的是哪个版本
```
