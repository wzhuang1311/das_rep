## 开始前：先把三个概念搞懂（不看会写错）

### 概念 1：`data` 是 10000×12，谁是时间谁是空间？

```
data.shape = (10000, 12)
              ↑     ↑
           时间轴   空间轴
          10000 个   12 个相邻的
          采样点     光纤位置点
```

- **横着的 12 个数** = 同一时刻，光纤上 12 个相邻位置测到的强度
- **竖着的 10000 个数** = 同一个位置，随时间变化的强度

论文 3 节说："每个样本由时域 10000 点和空域 12 个相邻点组成"。对上了。

**所以画图时**：我们想让"横轴=时间、纵轴=空间"，就要画 `data.T`（转置），
这样 `imshow` 得到的是 12 行 × 10000 列。**这一点想不到，图就是躺倒的。**

### 概念 2：为什么要看"差分信号"？

论文 Fig. 3 画的**不是原始数据，是差分后的数据**。差分就是隔一个点相减：

```python
# 沿着时间轴（axis=0）做一阶差分
data_diff = np.diff(data, axis=0)      # 形状变成 (9999, 12)
```

**为什么要有这一步？** 原始信号里有一个很大的"直流底"（背景光强），
它数值大、变化慢，会把事件引起的小波动**淹没**掉。
差分相当于高通滤波：**慢的变化被减掉了，快的变化被留下**。
挖掘、敲击这类"突变"事件就凸显出来了。

> 你机器上实测过：背景噪声样本的原始值范围是 **7828 ~ 8655**，
> 整个动态范围只有 800 多，而且大部分是缓慢漂移。
> 差分之后，事件带来的快速抖动才会显现。

### 概念 3：差分有负数，直接 `imshow` 会显示成一团黑

`imshow` 默认把最小值当黑、最大值当白。差分后的数据有正有负，
负值会被压到色标下端，**细节全看不见**。

解决办法：画图前取绝对值。

```python
np.abs(data_diff)
```
