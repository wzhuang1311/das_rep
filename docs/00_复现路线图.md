### 论文里两个模型的核心设定（复现时必须对齐）

**SVM（论文 4.1 节）**
- 每个样本是 10000×12 的矩阵（时间 10000 点 × 空间 12 点）
- 数据量太大，SVM 不能直接吃 → 必须**先手工提特征**
- 对 12 个通道各自提 16 个时域特征，对**原始信号**和**差分信号**各提一遍 = 每通道 32 个特征
- 12 通道 × 32 = **384 维特征向量** → 用 `MinMaxScaler` 归一化到 [0,1] → 送进 SVM
- 16 个特征是：最大值、最小值、峰峰值、均值、方差、标准差、能量、均方根、整流均值、波形因子、脉冲因子、峰值因子、裕度因子、峭度因子、峭度因子（原文重复了一次）、信息熵

**CNN（论文 4.2 节 + Table 3）**
- 输入：10000×12 的矩阵，**按每个样本自己的最大最小值归一化到 0~255**（模拟灰度图）
- 优化器 Adam，损失函数交叉熵，学习率 **0.01**，batch size **100**，epochs **50**
- 网络结构（论文 Table 3，注意原表排版有错位，以列标题为准）：

| 层 | 卷积核/步长/填充 | 输入尺寸 | 激活 |
|----|-----------------|---------|------|
| Conv1 | 200×3 / 50×1 / 1 | 1×10000×12 | ReLU |
| Pool1 | 2×2 / 2×2 | — | — |
| Conv2 | 20×2 / 4×1 / 1 | — | ReLU |
| Pool2 | 2×2 / 2×2 | — | — |
| Flatten | — | — | — |
| Linear | 输出 6 类 | 400 | — |

> ⚠️ Table 3 的输入/输出尺寸列在 PDF 里串行了，看起来自相矛盾（比如 Pool1 前面写 5×197×12）。
> **不要纠结这张表**，第一遍复现用"大卷积核 + 两层卷积 + 全连接"的等价结构即可。
> 等第一遍跑通、拿到 ≈94% 之后，再去对齐细节。这是新手最容易卡死的地方。

### 评估指标（论文 4.3 节，公式 1~4）
- precision = TP / (TP + FP)
- **NAR（误报率）= FN / (TP + FN)** ← 注意这篇论文的 NAR 定义和常规"虚警率"不同，它就是漏检率
- F1 = 2TP / (2TP + FP + FN)
- accuracy = (TP + TN) / (TP + FP + TN + FN)
- 6 类问题要**按类算 precision / NAR / F1**，再对 6 类取平均

## 三、复现路线（5 个阶段，建议按顺序，别跳）

| 阶段 | 做什么 | 产出物 | 预计 |
|------|--------|--------|------|
| **0** | 读懂论文 + 数据（就是本文件第一节 + 第二节） | 能口头说清"输入是什么、输出是什么、两个模型分别怎么做" | 0.5 天 |
| **1** | 数据 sanity check：统计数量、画 1 个样本、画 6 类对比图 | `results/stage1_*` 图片 + 一段结论 | 1 天 |
| **2** | **SVM 基线**：特征提取 → 归一化 → 训练 SVM → 混淆矩阵 | 准确率 + `results/svm_confusion.png` | 2~3 天 |
| **3** | **CNN 基线**：Dataset → 网络 → 训练循环 → 混淆矩阵 | 准确率 + `results/cnn_confusion.png` | 3~5 天 |
| **4** | 结果对比 + 写复现报告 | 报告 + 对比表（对齐论文 Table 4） | 1~2 天 |

**为什么 SVM 排在 CNN 前面？**
你刚学完鱼书的误差反向传播，正好会用上。SVM 不涉及反向传播，代码短、跑得快（几分钟出结果），
能让你先把"**数据怎么读 → 特征怎么造 → 结果怎么评**"这条链子走通。
这条链子在 CNN 阶段会原封不动复用。反过来先做 CNN，你会同时被"网络不收敛"和"数据读取错了"两件事夹击。

## 六、新手最容易踩的 5 个坑（先看一遍，能省你三天）

1. **一上手就调参**。第一遍复现的唯一目标是"跑通并拿到接近论文的数字"，
   不要一开始就想超过 94%。先复现，再改进——这也是导师的期待。
2. **把 10000×12 的矩阵当成 10000 个样本**。一个 `.mat` 文件 = 一个样本，
   不是 10000 个。训练集总样本数是 12,335，不是 12335×10000。
3. **数据泄漏**。论文明确写了训练测试按 8:2 随机划分且**无重叠**，而且官方已经替你分好了
   `train\` 和 `test\`。**直接用现成的两套目录，不要自己重新随机分**，否则会和论文数字对不上。
4. **忘了归一化**。论文里 SVM 用 MinMaxScaler 归一到 [0,1]，CNN 归一到 [0,255]。
   不做归一化，CNN 基本不收敛。
5. **只看 accuracy**。6 类样本数不均衡（451~2357），accuracy 会骗人。
   必须看**按类的 precision / NAR / F1**，这才是论文 Table 4 的内容。

| 术语 | 中文 | 一句话解释 |
|------|------|-----------|
| Φ-OTDR | 相位敏感光时域反射计 | 往光纤里打光脉冲，靠背向散射光感知沿线的振动 |
| DAS / DVS | 分布式声波/振动传感 | Φ-OTDR 的工程化叫法 |
| 时空矩阵（spatial-temporal） | — | 横轴时间、纵轴空间位置的二维图，本文是 10000×12 |
| NAR |  nuisance alarm rate | 本文定义为 FN/(TP+FN)，其实就是漏检率 |
| 峭度因子 | kurtosis | 描述信号波形尖锐程度的统计量 |
| 差分信号 | differentiated signal | 相邻时间点相减，突出变化、抑制缓慢漂移，论文 Fig.3 用的就是这个 |
